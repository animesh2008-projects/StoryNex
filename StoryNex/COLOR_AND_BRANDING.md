# STORYNEX — Color System & Brand Identity

**Tagline:** Every Story Has a Universe.  
**Personality:** Cinematic, editorial, minimal, intelligent, immersive, writing-first.

---

## 1. Palette Specification

| Token | Name | Hex Code | Purpose |
|---|---|---|---|
| `--background` | Void Black | `#0B0B0F` | Main app canvas, dark immersion |
| `--surface` | Surface | `#15151C` | Cards, sidebars, modals |
| `--surface-secondary` | Secondary Surface | `#1B1B24` | Nested panels, inputs, toolbars |
| `--border` | Border | `#252530` | Structural dividers and outlines |
| `--primary` | Story Violet | `#A78BFA` | Primary brand accent, selected tabs, key CTAs |
| `--primary-strong` | Deep Violet | `#7C3AED` | Hover states, button gradients |
| `--accent` | Electric Cyan | `#67E8F9` | Narrative intelligence indicators, AI badges |
| `--text-primary` | Primary Text | `#F4F4F5` | Headings, reading prose, high contrast |
| `--text-secondary` | Secondary Text | `#A1A1AA` | Body copy, descriptions |
| `--text-muted` | Muted Text | `#71717A` | Metadata, word counts, timestamps |

## 2. Semantic Feedback Colors

| Meaning | Hex Code | Usage |
|---|---|---|
| **Success** | `#4ADE80` | Saved status, continuity verified, canon anchor |
| **Warning** | `#FBBF24` | Continuity violation, missing API key |
| **Error** | `#F87171` | Deletion alerts, authentication errors, AI provider failures |

---

## 3. Brand Identity Rules
- **No generic AI sparkle icons as the primary logo:** STORYNEX uses a geometric cosmic folio icon representing a book opening into a galactic nexus.
- **Restrained motion:** Subtle transitions (160ms - 220ms) using cubic-bezier curves. Respects `prefers-reduced-motion`.
- **Serif Writing Priority:** The central chapter editor uses readable serif fonts (Georgia / Cambria) with generous line heights to preserve editorial focus.
